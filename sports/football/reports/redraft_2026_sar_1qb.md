# Draft Board — 2026 · 14-team 1QB PPR

_14-team · **ppr** · 1QB / 2RB / 2WR / 1TE / 1FLEX · 15 rounds (210 picks). Features from 2025._

_**The overall board is a pick order — draft down it.** Every projection is model-only; ECR/ADP are benchmarks and never inputs to a model number. The model can't score rookies, so the market (**1QB redraft-overall** ECR) is used for three things and nothing else: how many rookies belong in each position's top-N, which slot each takes in the order below, and **who is draftable at all** — a player no preseason board ranks is retired, unsigned, suspended or hurt, which the model can't see. Rookie rows are *italic* and carry no projection. The per-position tables are returning players only._
